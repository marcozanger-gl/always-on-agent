What happens between "you walked 300 m" and "a note lands on your phone". In production the agent wakes up when you move, not on a clock. Below is one event, from start to finish.

Moving wakes it, not a clock

The phone reports a new position only after a real move. The backend decides if it's worth a note right now, so you get a few good ones per walk, not a stream.

Memory belongs to each user

What the agent already told you and what you seem to like live in a database per user. Each run starts by reading it and ends by writing to it.

Same agent as the demo

Steps 4–9 are the routine we built: same instructions, same Wikipedia lookup, same rules. Only the trigger, the memory and the delivery change.
