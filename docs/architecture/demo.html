by the way. how the agent works

An always-on Claude agent that wakes up on a schedule, checks where you are, finds what's nearby on Wikipedia and leaves you a short "by the way" note. Nobody prompts it: the schedule does.

The issue is the state

The agent keeps no database. Each run counts the btw-stop:N markers in the issue to know which stop is next and which places it already suggested. Delete a comment and the walk redoes that stop.

Grounded, not invented

Snippets use only facts from the Wikipedia extract that nearby.py returns. If nothing new is nearby, it still posts the stop, so the walk keeps moving.

From demo to real life

Swap track.json for the phone's GPS and the issue comment for a push notification. The routine, the playbook and the lookup stay the same.
